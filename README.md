## 📖 Historia

> *"¿Qué pasaría si una persona completamente desconocida se sentara a tu lado durante un viaje de varias horas y terminara cambiando tu vida?"*

Acompáña a **Aranxita** en un viaje en tren de 12 horas. Controla sus pensamientos, decisiones y emociones mientras comparte el asiento con **Franxito**, un misterioso desconocido. Cada elección afecta la afinidad, la personalidad y el clima emocional, llevándote a **15 finales distintos**.

### 🌦️ Características

- **15 finales únicos** basados en afinidad, personalidad y clima
- **Sistema de diálogos interactivos** con efecto máquina de escribir
- **Clima dinámico** (sol, lluvia, nieve, tormenta, niebla, noche estrellada)
- **Motor de audio procedural** con piano Rhodes, ruido de vías y clima
- **Sistema de personalidad** con 8 arquetipos (Tímida, Divertida, Curiosa, etc.)
- **Galería de destinos** para coleccionar todos los finales
- **Logros desbloqueables**
- **Guardado/Carga** con hasta 3 ranuras + autoguardado
- **Modo sandbox climático** para explorar variaciones de la historia

## 🚀 Instalación y Uso Local

### Prerrequisitos

- **Node.js** 18+ 
- **npm** 9+

### Pasos

```bash
# 1. Clonar el repositorio
git clone https://github.com/Franeldramatico/MiRegaloPrincipal.git
cd MiRegaloPrincipal

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

### Construir para producción

```bash
npm run build
npm run preview
```

## 🎮 Cómo Jugar

1. **Inicio**: Presiona "Subir al vagón" para activar el audio
2. **Menú principal**: Haz clic en "Inaugurar Viaje (12 Horas)"
3. **Durante el viaje**: Lee los diálogos y elige entre las opciones de respuesta
4. **Controles**: Usa los botones superiores para guardar, ver historial, logros, música y ajustes
5. **Finales**: Cada decisión cuenta — explora diferentes combinaciones para descubrir los 15 finales
